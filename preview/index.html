时间线方案

TIMELINE A

粘性竖轨 + 横排时间指示器

左侧固定竖线，顶部气泡时间指示器跟随滚动。卡片通过连接线挂载到竖轨，自适应网格排列。

查看预览 → TIMELINE B

居中竖线 + 交替卡片

竖线位于内容区正中央，卡片左右交替排列。节点连接线指向竖线，时间标签在对侧。居中时间指示器跟随滚动。

查看预览 → TIMELINE C

渐变极简竖轨 + 浮动时间徽章

品牌色渐变竖线带辉光，浮动时间徽章显示日期+精确时间。卡片按日期分组，每组有独立时间标签，hover 显示品牌色侧边条。

电波图方案

ECG A

复古绿色荧光示波器

经典 CRT 风格，绿色磷光波形带厚重余晖拖尾。扫描线纹理 + CRT 弧面效果，BPM 实时波动显示。

查看预览 → ECG B

现代极简波形

纤细品牌色线条，波形下方柔和渐变填充。极淡基线网格，扫描头小光点带轻微辉光。克制优雅，适合融入 Hero。

查看预览 → ECG C

未来感双层粒子波形

主波形 + 紫色回声层叠加，粒子扫描头拖出尾迹。动态脉动网格 + 四角科技装饰线，实时频率/振幅数值。
